Envy for macOS

Stop pasting API keys into ~/.zshrc. Envy keeps your environment variables and secrets in one native app, with secrets in the Keychain, and gives every terminal and AI coding agent exactly what it needs for the folder it's in.

🔐 Secrets in the Keychain

API keys and tokens live in the macOS Keychain, not in plain text in your dotfiles where every program you run, coding agents included, can read them.

📂 Folder-aware, direnv-style

Link a project to a folder and its variables load the moment a terminal cds in, then unload when it leaves, restoring anything they overrode.

🎚️ One-click on/off

Switch a whole project or a single variable on or off from the window or the menu bar. Open terminals pick it up at their next prompt.

🤖 Built for coding agents

Claude Code, Codex, Cursor CLI, Gemini CLI and Aider get exactly what's switched on for the folder you start them in, and nothing else.

📥 Import everything

Scan a folder of code for .env, .env.local and .envrc files, plus .NET appsettings.json and user secrets, flattened to Section__Key.

🧭 Setup Assistant

Detects zsh or bash, ZDOTDIR and dotfile symlinks, connects your terminal, verifies a fresh shell, and moves plain-text secrets out of your startup files.
